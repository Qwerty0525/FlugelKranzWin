============================================================

------------------------------------------------------------

The published artifact is self-contained and therefore bundles the .NET 10
runtime and its libraries (the System.*, Microsoft.* and clr*/host* files next
to FlugelKranz.exe).

Runtime dependencies not bundled
------------------------------------------------------------

SteamVR and its OpenVR runtime are supplied by the user's Steam installation
and are not redistributed here; openvr_api.dll above is the client library
from the OpenVR SDK.

libmonado is supplied by the user's Monado / WiVRn installation and is not
bundled in this artifact. The Linux backend code remains in this repository
for reference but is not the target of this Windows fork.
