# FlugelKranzWin

Windows x64 / SteamVR용 자유 비행·무한 보행 도구입니다. 관성이 있는 Space Drag와 Pitch / Yaw / Roll 3축 회전을 모두 조합해 공간을 이동할 수 있습니다. 앱 이름과 실행 파일 이름은 `FlugelKranz`입니다.

이 저장소는 [FlugelKranz](https://github.com/ReinaS-64892/FlugelKranz)의 Windows용 파생판입니다. 이곳의 개발·배포·지원 대상은 Windows / SteamVR로 한정합니다. **Linux / Monado / WiVRn 판은 상위 저장소를 참고해 주세요.** 상위 저장소에서 이어받은 Linux 관련 코드는 남아 있지만, 이 저장소의 지원 대상은 아닙니다.

## 설치

Windows x64, SteamVR, 지원되는 HMD와 컨트롤러, 그리고 함께 들어 있는 전용 SteamVR 드라이버가 필요합니다. [빌드·설치·업데이트 절차](WINDOWS.ko.md)에 따라 앱과 드라이버를 배치하고 프레임 자세 보정을 설정해 주세요.

빌드하지 않고 쓰려면 [Releases](https://github.com/Qwerty0525/FlugelKranzWin/releases)의 zip을 풀고 [릴리스 zip으로 설치](WINDOWS.ko.md#릴리스-zip으로-설치) 절차에 따라 드라이버를 등록해 주세요.

Quest 2 + Touch / Virtual Desktop에서 시간 기반 보정을 켠 구성으로, 회전을 유지하는 동안과 회전 조작 중에 머리를 움직일 때 검은 테두리·화면 어두워짐·지터가 개선되었다는 보고를 실제 기기에서 받았습니다(2026-09-13). 그 뒤에 보고된 시야 흔들림도, 항등 변환일 때는 그대로 통과시키고 회전을 유지하는 동안에는 원래의 프레임 예측을 유지하도록 고친 뒤 해소되었다는 보고를 실제 기기에서 받았습니다(2026-09-14). 설정과 검증 범위는 [WINDOWS.ko.md](WINDOWS.ko.md#동작-확인)에 적어 두었습니다.

## 처음 조작

1. SteamVR을 실행하고, HMD와 양손 컨트롤러가 추적되는 상태에서 `FlugelKranz.exe`를 실행합니다.
2. `F` 모드를 고르고 ON으로 켭니다. 조작 버튼은 한 번 뗀 다음에 눌러 주세요.
3. Touch의 그립을 누른 채 손을 움직이면 공간을 끌어당깁니다. 움직이는 도중에 놓으면 설정에 따라 관성이 남습니다.
4. 왼쪽 X / 오른쪽 A를 누르고 손목을 돌리면 3축 모두로 회전합니다.
5. OFF는 비행과 관성을 멈춥니다. F 모드에서 Drag가 켜져 있으면 Drag만 조작할 수 있고, `↻`는 위치·자세를 원래대로 되돌립니다.

## 조작 사양

### 시작과 공통 조작

Windows에서는 OFF 상태로 시작하고 저장된 모드를 복원합니다. SteamVR과 전용 드라이버를 실행한 뒤 ON으로 켜 주세요. 연결할 수 없으면 설정 화면에 오류를 표시합니다. 큰 `ON` / `OFF` 버튼은 현재 동작 상태를 나타내며, 누르면 전환됩니다. OFF로 해도 현재 위치·자세는 유지하지만, 조작 중인 잡기와 관성은 끝납니다. F 모드에서 Drag가 켜져 있으면 입력을 놓았다가 다시 잡아서 Drag만 쓸 수 있습니다. 비행 OFF 중에는 머리 조종·스틱 추진·놓을 때의 관성이 꺼집니다. Drag도 끄면 공간 조작이 멈춥니다.

둥근 `I` / `F` 버튼은 무한 보행(Infinite Walking)과 자유 비행(Free Flight) 전환, `⚙`는 설정, `↻`는 연결 시점의 위치·자세로 되돌리는 전체 리셋입니다. 전체 리셋은 ON을 유지한 채 즉시 위치·자세를 되돌립니다. ON으로 켠 뒤, 모드를 전환한 뒤, 전체 리셋 뒤에는 누르고 있는 조작 입력을 한 번 놓고 다시 잡아 주세요.

무한 보행에서 자유 비행으로의 전환은 현재 위치·자세를 유지한 채 즉시 끝납니다. 자유 비행에서 무한 보행으로 전환하면 1초에 걸쳐 연결 시점의 높이로 돌아가고, 연결 시점의 자세를 기준으로 한 Yaw만 남기고 피치와 롤을 수평으로 되돌립니다. 전환 중에는 Drag / Turn을 받지 않습니다.

### 컨트롤러 입력

기본 SteamVR Input 바인딩입니다. 누르고 있는 동안 해당 조작이 켜집니다.

| 컨트롤러 | Drag(공간 이동) | Turn(공간 회전) |
| --- | --- | --- |
| Touch 왼손 / 오른손 | 그립 누르기 | 왼쪽 X / 오른쪽 A 누르기 |
| Valve Index 왼손 / 오른손 | 트리거 누르기 | A 누르기 |

`⚙` → "Open SteamVR controller bindings"(「SteamVR のバインド設定を開く」) 또는 `FlugelKranz.exe --bindings`로 바꿀 수 있습니다. 앱 이름은 `FlugelKranz`, 앱 키는 `org.flugelkranz.windows`입니다. 좌우 각각의 Drag / Turn / reset_hold를 버튼이나 터치에 할당할 수 있습니다. 상위 Linux 판의 터치 조합이나 Index 감압 설정은 쓰지 않습니다.

`reset_hold`는 기본적으로 할당되어 있지 않습니다. 필요하면 SteamVR에서 할당해 주세요.

| 입력 | 무한 보행(I) | 자유 비행(F) |
| --- | --- | --- |
| 한 손의 reset_hold를 1초 유지 | 높이 리셋 | 수평 리셋 |
| 양손의 reset_hold를 1초 유지 | 자유 비행으로 전환 | 무한 보행으로 전환 |

양손 유지에 의한 모드 전환이 한 손 리셋보다 우선합니다. UI의 `I` / `F`와 `↻`도 쓸 수 있습니다.

### 머리 조종 시험 기능(Windows / F 모드)

F 모드에서는 머리 조종(UI 표기 Head pilot)과 강화된 스틱 추진이 기본으로 켜져 있습니다. 설정의 "Free flight — Head pilot (experimental)"(「自由飛行 — 頭部操縦（試作）」)에서 바꿀 수 있습니다. 저장된 켜기/끄기 설정은 유지합니다. SteamVR 개발자 설정 **Experimental overlay input overrides**를 켜야 합니다. 꺼져 있으면 이유를 표시하고 연결을 끝냅니다.

- Touch의 **X / A를 짧게 누르면** 머리 조종을 ON / OFF합니다. 시험 기능을 쓰는 동안에는 원래의 컨트롤러 Turn을 대신합니다. 짧게 누른 버튼을 떼는 순간 전환되며, ON이 된 시점의 물리적인 머리 방향을 중립으로 삼습니다. 더블클릭 판정을 위한 대기 시간은 없습니다.
- ON인 동안에는 중립에서 머리를 기울인 만큼 연속으로 회전합니다. 아래를 보면 앞으로 구르고, 위를 보면 뒤로 구르고, 좌우로 기울이면 롤, 좌우를 돌아보면 선회합니다. 중립으로 돌아오면 회전 명령은 0이 됩니다.
- **X / A를 0.5초 길게 누르면** 이동·회전 관성을 0으로 만들고, 위치·자세와 머리 조종의 ON/OFF는 유지합니다. 길게 누른 뒤 떼어도 조종 상태는 바뀌지 않습니다. 조종이 ON인 채로 머리를 기울이고 있거나 스틱 입력이 있으면, 그 뒤의 명령으로 다시 움직입니다.
- **왼쪽 스틱**은 현재 시선을 기준으로 추진합니다. 위로 입력하면 보고 있는 방향, 아래로 입력하면 그 반대 방향으로 가속합니다. 좌우 입력은 무시합니다. 머리 조종이 OFF여도 추진할 수 있습니다. 스틱을 놓아도 이동 관성은 남습니다.
- Drag는 별도 설정 "Free flight — Drag"(「自由飛行 — Drag」)에서 켜고 끌 수 있습니다(기본은 켜짐). 잡는 조작은 예전처럼 누르고 있는 동안입니다. 잡는 도중에 끄면 놓을 때의 가속이 생기지 않으며, 다시 켠 뒤에는 버튼을 놓고 다시 잡습니다. Windows에서는 F 모드이면서 Drag가 켜져 있으면, 앱 시작 시나 설정 변경 시에도 비행 OFF인 채로 연결해 Drag를 쓸 수 있습니다. Drag 중에는 손을 고정하는 조작을 우선하며, 머리 회전 명령과 스틱 가속은 적용하지 않습니다. 시험 기능을 끄면 X / A는 원래의 Turn으로 돌아갑니다.
- **대시보드가 열려 있는 동안에는 모든 조작·이동 관성·회전 관성을 멈추고** 위치·자세를 유지합니다. 머리 조종과 입력 점유도 해제합니다. 닫은 뒤에는 스틱과 조작 버튼을 놓고, 머리 조종은 다시 클릭해서 시작합니다.

시험 기능의 고정값은 머리 데드존 3°, 25°에서 최대 90°/초(그 사이는 2차 곡선), 스틱 데드존 15%, 최대 가속도 14 m/s², 스틱 가속 시 속도 상한 12 m/s입니다. 스틱으로 추진하는 동안에는 이동 관성의 자연 감쇠를 멈추며, 최대 입력에서는 약 0.86초 만에 속도 상한에 도달합니다. 스틱을 놓으면 기존 감속 설정을 씁니다. 회전 관성의 감쇠와 속도 벡터의 회전은 기존 설정을 유지합니다. 이전에 요청받은 OVRAS 수준의 기본값 조정과는 별개입니다.

시험 기능을 켠 F 모드에서 앱이 ON인 동안에만 왼쪽 스틱과 X / A의 입력 소스를 높은 우선순위로 점유합니다. VRChat의 바인딩을 지울 필요는 없습니다. 오른쪽 스틱 누르기와 B는 쓰지 않습니다. 기존 개인 바인딩에는 `/actions/pilot`의 새 할당이 없을 수 있으니 SteamVR에서 확인해 주세요. Index의 기본값은 양손 A입니다.

이 시험 기능의 입력 점유·대시보드 처리·다른 오버레이와의 공존은 실제 기기에서 확인하지 않았습니다. 플로팅 패널 조작 감지는 구현되지 않았으며, 패널이 표시되기만 해서는 점유를 해제하지 않습니다. main에는 렌더링 보정 수정도 통합되어 있습니다. Quest 2 + Touch / Virtual Desktop에서는 알려진 흔들림이 해소되었다는 보고를 받았습니다.

### 무한 보행 모드

무한 보행에서는 관성을 쓰지 않습니다. 한 손 Drag는 잡은 손의 위아래 이동만 공간의 Y 이동에 그대로 반영합니다. 양손 Drag는 양손 위치의 중점을 기준으로 하며, 위아래 이동량을 2배로 합니다. 손을 옆이나 앞뒤로 움직여도 Drag에는 반영되지 않습니다.

Turn은 항상 HMD 위치를 중심으로 하는 Y축 회전입니다. 한 손 Turn은 잡은 컨트롤러의 Yaw를 상쇄하고, 양손 Turn은 컨트롤러의 기울기가 아니라 HMD의 Yaw를 상쇄합니다. 한 손과 양손이 바뀌는 시점에 현재 자세를 새 시작 자세로 삼으므로, 전환만으로는 공간이 튀지 않습니다.

한 손 reset_hold에 의한 높이 리셋은 Y 위치만 1초에 걸쳐 연결 시점의 높이로 되돌립니다. X/Z 위치와 자세는 유지합니다. 리셋 중에는 조작을 받지 않으며, 끝난 뒤에는 입력을 놓고 다시 잡습니다.

무한 보행 전용 **Drag smoothing**(ドラグスムーズ)은 Drag, Turn, 양손 Turn(Turn Head)의 추종을 각각 부드럽게 합니다. 모두 기본값은 `0.0`초이고, `0.0`～`1.0`초 범위에서 조정할 수 있습니다. `0.0`초에서는 보간하지 않고 바로 반영하며, 값을 키우면 추종이 완만해집니다.

**Infinite walking boost**(無限歩行ブースト)는 Turn 중 HMD의 수평 이동을 진행 방향으로 더해, 회전할 때 발이 뒤로 미끄러지는 느낌을 보정합니다. 보정값 "Strength"(「補正値」)는 더할 이동량의 배율로, 기본값은 `0.6`, 범위는 `0.0`～`2.0`입니다. `0.0`이면 꺼지고, `1.0`이면 측정한 수평 이동과 같은 거리를 더합니다.

### 자유 비행 모드

한 손 Drag는 잡은 컨트롤러의 위치를 공간에 고정하듯 모든 축으로 이동하고, 양손 Drag는 양손 위치의 중점을 고정합니다. 두 번째 손이 더해지면 그 시점의 중점으로 다시 잡기 때문에 공간이 튀지 않습니다. 양손 Drag에서 한 손을 놓으면 Drag 전체가 끝납니다. 남은 손의 입력도 한 번 놓고 다시 잡아 주세요.

한 손 Turn은 잡은 컨트롤러의 회전을 상쇄하듯 모든 축으로 회전합니다. 기본 회전 중심은 HMD 위치입니다. 설정에서 유효한 HMD·좌우 컨트롤러 위치의 중점으로 바꿀 수 있습니다. Drag와 Turn을 동시에 쓰는 동안에는 이 설정보다 Drag 중인 손, 또는 양손 Drag의 중점을 회전 중심으로 우선합니다.

양손 Turn은 두 컨트롤러를 잇는 직선을 축으로 하는 회전 성분만 반영합니다. 두 번째 손이 더해질 때나 양손에서 한 손으로 돌아갈 때는 그 시점의 위치·자세로 다시 잡으며, 전환 자체로는 각속도를 만들지 않습니다. 한 손 Drag와 다른 손의 Turn은 동시에 쓸 수 있어, Drag의 고정점을 유지한 채 그 주위를 회전할 수 있습니다.

양손 Drag 중에는 이동 관성과 회전 관성 모두에 Drag brake(ドラグブレーキ)를 겁니다. 한 손 Drag는 이동 관성만, Turn은 회전 관성만 멈춥니다. 조작을 놓으면 그 시점에 측정한 이동 속도 또는 각속도를 관성으로 이어받습니다.

한 손 reset_hold에 의한 수평 리셋은 그 시점에 표시되고 있는 HMD의 정면을 가장 가까운 수평 방향에 맞추고, 피치와 롤을 1초에 걸쳐 되돌립니다. 회전 중에는 일반 Turn과 같은 회전 중심을 고정하며, 동시에 Drag하고 있으면 Drag 위치를 우선합니다. 리셋 중에는 조작을 받지 않으며, 끝난 뒤에는 입력을 놓고 다시 잡습니다.

자유 비행 모드에서 쓰는 관성 파라미터는 다음과 같습니다.

- **Inertia cutoff**(慣性カットオフ): 놓을 때의 속도가 Drag `5 cm/s`, Turn `45 °/s` 미만이면 관성을 시작하지 않습니다. 이미 시작된 관성이 감속으로 임계값 아래로 내려가도 멈추는 데에는 쓰지 않습니다. 체크를 해제하면 꺼집니다.
- **Inertia acceleration multiplier**(慣性加速倍率)는 놓을 때의 속도를 Drag·Turn 별로 `0.0`～`5.0`배 합니다. 기본값은 Drag `5.0`, Turn `0.4`입니다.
- **Z acceleration**(Z加速)은 플레이어의 정면 방향을 기준으로, Drag를 놓을 때의 앞뒤 성분만 추가 배율로 강화합니다. 방향과의 내적의 절댓값을 가중치로 쓰므로 옆 방향으로는 추가 가속을 걸지 않습니다. 범위는 `1.0`～`5.0`, 기본값은 `2.0`입니다.
- **Inertia acceleration boost mode**(慣性加速ブーストモード)를 켜면, Drag 중 컨트롤러의 이동 속도가 컷오프를 넘는 동안에는 Drag brake를 걸지 않고, 놓을 때의 가속을 남아 있는 관성에 더합니다. 컨트롤러가 다시 느려지거나 멈추면 브레이크도 다시 걸립니다. 더한 뒤의 속도는 남아 있는 관성과 이번에 놓을 때의 가속 중 큰 쪽을 기준으로 최대 배율 "Max multiplier"(「最大加速倍率」)로 제한되며, 기본값은 켜짐·`4.0`배(`1.0`～`6.0`)입니다.
- **Vector rotation multiplier**(ベクトル回転倍率)는 Turn으로 현재 이동 관성 벡터를 돌리는 비율입니다. 기본값 `1.0`에서는 Turn을 완전히 따라가 곡선 궤도를 만들고, `0.0`에서는 회전 전의 진행 방향을 유지합니다.
- **Inertia deceleration**(慣性減速)은 초당 지수 감쇠율입니다. `0.0`은 감속 없음, `10.0`은 급격한 감속이며, 기본값은 `2.0 /초`입니다.
- **Deceleration exemption**(慣性減速免除)의 시간은, 현재 속도에서 실용상 정지 속도까지 일반 감속으로 줄어드는 데 걸릴 예상 시간에 대한 비율입니다. Drag와 Turn을 따로 설정할 수 있으며, 기본값은 Drag `0.20`, Turn `0.15`입니다. 면제 비율 "Exemption ratio"(「免除割合」)의 기본값은 공통으로 `0.90`입니다.
- **Drag smoothing**은 Drag와 Turn의 추종을 각각 부드럽게 해 트래킹의 미세한 떨림을 억제합니다. 범위는 `0.0`～`1.0`초, 기본값은 Drag `0.01`초, Turn `0.05`초입니다. `0.0`초에서는 보간하지 않고 바로 반영합니다. 관성 속도는 이 설정과 관계없이 실제 컨트롤러 조작에서 계산합니다.
- **Drag brake**는 Drag / Turn을 잡기 시작할 때 해당 관성을 완전히 감쇠시킵니다. 한 손 Drag는 선속도, Turn은 각속도, 양손 Drag는 선속도와 각속도 모두에 작용합니다. 적용 시간 "Ramp time"(「適用時間」)은 `0.0`～`1.0`초로 설정할 수 있으며, 기본값은 `0.40`초, `0.0`초이면 즉시 멈춥니다. 작동하면 해당 관성 감속 면제를 해제합니다.

HMD 트래킹을 잃은 동안에는 ON 상태, 조작 상태, 관성을 유지한 채 공간 갱신을 일시 정지하고, 복귀하면 다시 시작합니다. 손의 트래킹을 잃으면 그 손의 조작은 해제됩니다. 양손 Turn은 추적이 남은 손을 기준으로 다시 잡아 계속합니다. 양손 Drag는 한 손을 잃으면 전체를 해제하므로, 남은 손도 입력을 놓은 뒤 다시 잡아 주세요.

정상 종료 시에는 비행 변환을 해제합니다. OFF 중에는 연결을 유지해 위치·자세를 유지합니다. 앱의 heartbeat가 500 ms 끊기면 작동 중인 드라이버는 변환을 해제하며, 복귀하려면 다시 연결해야 합니다. 연결 시점의 SteamVR Standing 기준 공간이 바뀌면 조작을 멈춥니다.

### 표시 언어·명령 전송 간격·중력 나침반·진단 로그

- **표시 언어**: 메인 화면 오른쪽 위의 `ENG` / `JPN`으로 영어와 일본어를 전환합니다(한국어 표시는 아직 없습니다).
- **Command interval (experimental)**(「指令の送信間隔（試験的）」): 기본값은 "High rate (about 3 ms)"(「高頻度（約 3 ms）」)입니다. 비행 명령을 잘게 나눠 보내, 이동 중 아바타의 몸과 머리가 어긋나는 떨림을 줄입니다. 끄면 예전의 약 15.6 ms로 돌아갑니다. 전환은 바로 반영되며, 던지기와 관성 이동 거리는 예전과 거의 같습니다.
- **Gravity compass**(「重力コンパス」): 손등 위에 작은 반투명 구를 띄워, 보이는 실제 방의 방향을 보여 줍니다. 빛나는 점이 실제 아래(중력), 흰 점이 비행 중인 VRChat 월드의 아래입니다. 배포판의 기본값은 꺼짐이며, Gravity compass → Show(「重力コンパス」→「表示する」)로 켭니다(기본은 오른손). SteamVR 오버레이라서 VRChat의 조작이나 화면에는 영향을 주지 않습니다.
- **Save diagnostic logs…**(「診断ログを保存…」): Diagnostic logs(「診断ログ」)에서 SteamVR·SlimeVR·Virtual Desktop·FlugelKranz 로그와 summary.txt를 zip 하나로 묶어 `문서\FlugelKranz Logs\`에 저장합니다. PC 이름·Windows 사용자 이름·사용자 폴더 경로는 바꿔 넣지만, 그 밖의 정보(기기 시리얼 번호 등)는 남으므로 공개하기 전에 내용을 확인해 주세요. 아무것도 전송하지 않습니다. SteamVR을 닫은 뒤(이 창은 연 채로) 저장하면 세션 전체가 남습니다. 문제가 있으면 zip을 첨부해 [GitHub Issues](https://github.com/Qwerty0525/FlugelKranzWin/issues)에 보고해 주세요.

앱 버전은 창 제목에 표시합니다.

## 설정 저장

설정은 바뀔 때마다 `%USERPROFILE%/.config/FlugelKranz/config.json`에 저장됩니다. `FLUGELKRANZ_CONFIG`로 저장할 파일을, `XDG_CONFIG_HOME`으로 설정 디렉터리를 바꿀 수 있습니다. 각 설정의 리셋 버튼은 그 항목을 기본값으로 되돌립니다.

## 구성과 개발

```text
FlugelKranz.exe(Avalonia / Windows)
  ├─ Core: Drag / Turn, 관성, 모드 제어
  └─ DriverFlightRuntime: SteamVR Input + 공유 메모리 IPC
       ├─ 변환 전 물리 자세를 읽음
       └─ 비행 변환을 전용 SteamVR 드라이버로 보냄
            ├─ tracked device 자세에 이동·회전을 적용
            └─ Direct Mode 프레임 자세를 물리 HMD 자세로 보정
```

게임에 넘기는 비행 후 자세와 HMD 표시 보정에 넘기는 물리 자세를 나눕니다. 조작 계산에는 변환 전 자세를 써서, 비행 결과가 입력으로 되돌아오는 피드백을 막습니다. Chaperone이나 VRChat의 수평선 설정은 바꾸지 않습니다.

개발 절차는 [WINDOWS.ko.md](WINDOWS.ko.md), 좌표 변환·IPC·렌더링 보정은 [드라이버 문서](native/driver/README.md)(일본어), 작업 규칙은 [AGENTS.md](AGENTS.md)(일본어)를 참고해 주세요.
